## 🚀 Projetos em destaque

### 📊 Ciência de Dados & Machine Learning

[**Telecom X — Análise de Churn**](https://github.com/elisvw/TelecomX)

Análise da evasão de clientes de uma empresa fictícia de telecomunicações, utilizando ETL e análise exploratória para identificar padrões e gerar insights de negócio.

- Preparação e transformação de dados com Pandas e NumPy.

- Visualização de padrões de evasão por tipo de contrato e tempo de permanência.

- Identificação de uma taxa de churn de 25,8%, com destaque para contratos mensais e os primeiros meses de relacionamento.

**Tecnologias:** Python · Pandas · NumPy · Matplotlib · ETL · Análise Exploratória de Dados (EDA)

[**Telecom X — Predição de Churn**](https://github.com/elisvw/TelecomX_pt2)

- Desenvolvimento de modelos de Machine Learning para prever a evasão de clientes, dando continuidade à análise exploratória do projeto anterior.

- Comparação dos algoritmos Random Forest e KNN.

- Avaliação com métricas de classificação e análise da importância das variáveis.

Seleção do Random Forest como modelo final.

**Tecnologias:** Python · Pandas · Scikit-learn · Plotly · Yellowbrick · Machine Learning

[**Spotify Songs Classification**](https://github.com/elisvw/Spotify-Songs-Classification)

Classificação de músicas do Spotify em categorias de músicas lentas e agitadas utilizando algoritmos de Machine Learning.

- Comparação entre Regressão Logística, KNN e Random Forest.

- Otimização de hiperparâmetros com GridSearchCV.

- Modelo final com 0,82 de acurácia e 0,90 de ROC-AUC.

**Tecnologias:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Machine Learning

### 🤖 Inteligência Artificial & Processamento de Linguagem Natural

[**Assistente Virtual — PET-Saúde Digital**](https://github.com/PET-SaudeDigitalG4/assistente_virtual_pet_saude)

Projeto colaborativo desenvolvido no contexto do PET-Saúde Digital, com foco no uso de tecnologias para apoiar a Atenção Primária à Saúde e facilitar o acesso a informações e serviços de saúde.

- Desenvolvimento de um assistente virtual utilizando Python, NLP e técnicas de Retrieval-Augmented Generation (RAG) para recuperação de informações em documentos de saúde.

- Construção de pipelines RAG com LangChain e FAISS, integrando busca semântica e recuperação de contexto para apoiar a geração de respostas.

- Integração de modelos de linguagem via API e desenvolvimento da comunicação com o WhatsApp utilizando Evolution API.

- Estruturação e processamento de dados de entrada e saída em JSON para integração entre os componentes do sistema.

**Tecnologias:** Python · NLP · RAG · LLMs · LangChain · FAISS · FastAPI

[**Assistente Hospitalar — Reconhecimento de Voz**](https://github.com/elisvw/assistente-hospitalar)

Aplicação em contexto acadêmico de reconhecimento de fala para interpretar comandos de voz relacionados a funcionalidades de um ambiente hospitalar.

- Captura de áudio pelo microfone e transcrição automática da fala.
- Processamento de transcrições para identificar comandos.
- Encaminhamento das ações reconhecidas para módulos específicos, como painel de enfermagem, leito, iluminação e sirene.
- Organização do código em módulos e implementação de testes automatizados.

**Tecnologias:** Python · Hugging Face Transformers · Wav2Vec2 · PyTorch · unittest
